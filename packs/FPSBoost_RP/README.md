# FPS Boost (resource pack)

Install: open `dist/FPSBoost.mcpack` -> Settings > Global Resources -> activate it -> restart the game.

What it changes:
- Main menu panorama replaced with tiny flat images (less work on the start screen)
- Vignette, pumpkin blur and clouds made invisible
- ~60 particles that spawn a lot turned off (campfire smoke, rain splashes, falling dust, portals, explosions, block-break bits, ash/spores, etc.)
